# STOTT Pilates 肌肉學自考圖卡 ☀

110 條肌肉的自學圖卡,涵蓋 12 個解剖章節,內建六種學習模式:

- **圖卡瀏覽** — 全部肌肉一覽,含中英名、動作、起止點、校註
- **看圖認名** — 圖片在前,填中文或英文名
- **看名選圖** — 四選一圖片題
- **完整回想** — 五項翻牌核對(EN/ZH/A/O/I)
- **模擬考** — 隨機抽題 4 選 1,7 種題型可選,A/B/C/D 評等
- **統計記錄** — 各章進度、考試歷史、需加強清單

## 校註

40 條肌肉附有校註,記錄原始 Word 教材的拼字錯誤、學理修正、與 STOTT 標準對照的補充說明。主要欄位忠於原文,校註單獨呈現。

## 技術

純前端,無後端;進度與統計儲存於瀏覽器 localStorage。資料以 `data.json` 提供,圖片於 `images/` 資料夾。

部署至任何靜態網站服務(GitHub Pages、Cloudflare Pages、Netlify 等)即可。
